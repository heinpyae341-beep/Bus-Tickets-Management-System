Global Admin

Local Admin account များကို စီမံပြီး လုပ်ငန်းဒေတာများကို ကြည့်ရှုနိုင်ပါသည်။ Bus, Trip, Route, Ticket များကို ဤအပိုင်းမှ ပြင်ဆင်၍မရပါ။

● ကြည့်ရှုခွင့်သာ
အသုံးပြုနေသော ဘတ်စ်ကား
စီစဉ်ထားသော လမ်းကြောင်း
ရောင်းပြီးလက်မှတ်
ဝင်ငွေ ကျပ်

👤 Local Admin အသစ်ဖန်တီးရန်

🔐 ခွင့်ပြုချက်အကျဉ်း

Global Admin: Local Admin ကို စီမံရန်၊ Bus / Trip / Route / Ticket ကို ကြည့်ရန်

Local Admin: Bus / Trip / Route / Ticket ကို စီမံရန်နှင့် Ticket ထုတ်ရန်

👥 Local Admin စာရင်း

Global Admin သီးသန့်စီမံမှု
အမည် အီးမေးလ် Username Role Status လုပ်ဆောင်ချက်

🚌 ဘတ်စ်ကားနှင့် ခရီးစဉ်များ

Bus → Route → Trip ဆက်စပ်ဒေတာ
Bus အမျိုးအစား ခုံ ထွက်ခွာရာ ရောက်ရာ အကွာအဝေး Route ရက်စွဲ အချိန် လွတ်ခုံ အခြေအနေ

🎫 Route နှင့် Ticket ကြည့်ရှုရန်

Route နှင့် သက်ဆိုင်သော Ticket ကို တစ်ကြောင်းတည်းတွင်ပြ
Route Trip ရက်စွဲ အချိန် လွတ်ခုံ ဈေးနှုန်း Ticket ID ခရီးသည် ဖုန်း ထိုင်ခုံ ပမာဏ Ticket Status
